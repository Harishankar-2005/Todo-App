# Todo-App

A simple and clean Todo application built with HTML, CSS, and JavaScript.

## Features

- Add tasks with a due date
- Delete tasks
- Data persists after page refresh using localStorage
- Clean responsive UI

## How to Use

1. Enter a task in the text field
2. Pick a due date
3. Click **Add** to save the task
4. Click **Delete** to remove a task

## Project Structure

```
index.html    # Markup and structure
script.js     # App logic and localStorage handling
style.css     # Styling and layout
```

## Tech Stack

- HTML5
- CSS3 (CSS Grid, Google Fonts)
- Vanilla JavaScript (localStorage for persistence)
